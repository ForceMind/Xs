# Xs · 更纯粹、更好用的 X

[简体中文](README.md) | [English](README.en.md)

**Xs 是独立研发、本地优先的 X 使用增强工程。** 以官方 X 网页承担浏览与社交，在应用自己的本机资料库中提供打开历史、收藏分类、本人内容索引，以及规划中的图片/视频下载、资源管理和系统分享。不修改官方 X APK，不建设新社交后台或账号代理。

> **当前仍是 W0 验证阶段，不是完整客户端。** 浏览容器、原生资料库、手动保存链接与“分享到 Xs”入口已有代码；自动网页记录、完整收藏快照、媒体下载器和对外文件分享尚未交付。真实 X 登录/媒体/真机兼容性仍需验收。

## 用户确认的目标

**打开即记历史**：开启后在 Xs 内主动进入帖子详情即记录，不需要再点保存、不设停留门槛。停留/刷到是独立可选事件。刷新、旋转和正文补载不虚增次数。本人转帖只在动作成功或已确认档案导入时建立行为记录。

**Xs 自己的收藏**：使用「收藏到 Xs」按钮保存可见正文、链接和来源并分类；不调用 X 的书签/点赞/转帖功能。资料属于本机应用，不属于当前 X 登录账号。退出或切换 X 不删除收藏、历史和下载；浏览会话与本地资料是不同层次。

**下载和资源库**：支持图片、图组和视频的主动下载、本地预览、来源追溯、分类、任务管理与删除。不同媒体格式、流媒体和续传能力以实现及实测为准，不把缓存、播放列表或半个文件冒充完整下载。

**分享实际文件**：选择链接、正文、图片或视频，通过系统分享菜单交给微信、QQ、飞书、Telegram 等支持相应格式的已安装应用，再选择会话并确认。Direct Share 会话入口取决于目标应用；Xs 不读取聊天凭证或自动发送，也不把调起分享当作送达。

## 当前可测试的手动流程

浏览器菜单「保存当前帖子链接」「我的本机资料库」，以及 Android 分享菜单中的「保存到 Xs」，提供原生确认的本地链接保存。首次使用明确创建本机空间，不假装验证了 X 账号。重复保存不生成虚假阅读事件。

当前手动模式不读取网页 DOM、Cookie、私信，不自动记录刷过的内容。它是主产品的补充入口，不是让用户永远手工收藏每条历史的替代方案。

## 隐私与数据

记录默认关闭并独立授权。自动采集只处理允许的帖子区域，登录、验证、私信和编辑器排除。新增资料不向 Xs 服务器同步；X 网页自身仍联网。用户主动分享到其他应用后，接收应用按自己的方式处理内容，不承诺分享后数据仍只在本机。

取消收藏、清历史、删下载、清缓存和退出 X 分开处理。旧资料不静默合并或破坏性重建；来源、时间和快照质量如实记录。SQLite 当前不应被描述为已加密。网页不能读取整库、执行 SQL、导出、删除或开启记录。
