# Xs 官方网站 / Xs website

[中文](README.md) · [English](README.en.md)

这里保存 Xs 跨平台官方网站的**独立、可运行静态单文件版本**，不会修改 Android 客户端源码。

## 运行

打开 `website/index.html`，或将 `website/` 作为静态站点目录提供服务。无需账户、构建工具或后端。页面中的帖子、收藏、搜索和刷新都只处理内存中的**演示数据**；它不是 X 网页的真实接入，也不是 X Corp. 官方网站。

## 设计与交互

- 黑白、高对比、克制的科技视觉；支持响应式及中英文切换。
- 手机与桌面布局切换；Android 是当前研发方向，Windows/macOS 是规划中，不暗示已发布。
- 可操作的浏览 → 模拟刷新 → 找回 → 搜索 → 收藏演示；可管理分类和备注、取消收藏、重置示意数据。
- 支持键盘操作与减少动态效果设置。
- 「最近时间线」单独默认关闭，启用后默认 48 小时及全应用 100 MiB 可调，**不等于已读或长期收藏**。
- 尚无正式发行版，不提供虚假的下载入口；明确标注演示图和验证边界。

## 源码与部署边界

本目录的 `index.html` 为可独立运行、内嵌样式和脚本的完整静态交付件，不依赖 Android 代码，也不将演示数据发送到真实 X 账户。此前单独准备的 TypeScript 项目、测试和截图包不是此处的源码树；如果要继续模块化开发，应将该项目包另外导入并重新校验构建。

原网站是 **独立 Sites 项目**，本仓库的提交**不会自动发布**到 `https://xs-local-first.kenneth42.chatgpt.site`。必须通过原项目的授权部署流程，保持原有项目身份和访问策略，不能新建替代站点。本次仓库更新仅保存可运行官网文件，不声称线上同步完成。
