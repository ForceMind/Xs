# Xs 完整实施计划 v2

日期：2026-11-06。基线：`eb5aa4dbbb0499fb632202a27aaf24e898718818`。范围依据：[产品要求](product.md)、[ADR-0002](adr/0002-local-library-media.md)、[ADR-0003](adr/0003-native-pull-delivery.md)。

**这是可执行研发计划，不是功能完成报告。下面新增工作包均未因本次文档提交而完成。** 统一跟踪 [Issue #4](https://github.com/ForceMind/Xs/issues/4)。

## 1. 产品闭环与边界

主体验：在 Xs 正常刷 X → 点开帖子即记历史 → 可搜索可分类 → 点「收藏到 Xs」独立保存 → 下载所选图片/视频 → 资源库预览 → 系统分享给目标应用/会话。

打开历史开启后，不需要再点保存，也不要求停留 1.2 秒。停留记录另行授权。资料库属于 Xs，不以当前 X 登录身份作为所有者；退出或切换 X 不删除、隐式切走收藏与资源。本人转帖的执行账号仅是可选行为元数据，未知时不能冒充已确认。

不修改官方 APK、不新建社交后端、不读取私信/草稿/凭证、不以手动分享收藏替代自动历史。不因主线需要增强而完整重写已有数据库或引入多套浏览器内核。

## 2. 双轨推进，分开验收

- **开发轨**：浏览底座对照、资料迁移、合成 X 页面、观察去重、收藏、下载任务、文件分享可以离线并行实现。
- **兼容轨**：目标手机的 X 直接登录/2FA/会话保持、帖子/媒体/外链，及接收应用文件分享分别实测。

W0 是启用真实站点自动采集和发布的验证门槛，不是禁止写离线观察器或资源模块的理由。未验证的采集不能在真实网页默认开启；不以绕过登录挑战、复制 Cookie 或伪装浏览器解决失败。

## 4. 交付批次与依赖

### A：正常浏览与自动打开历史

XS-01/02 与 XS-03/04 并行，随后串起 XS-05/06。完成应用资料所有权、即开即记、快照补全、离线查询和返回原帖。旧资料不丢失；真实 X 登录/核心浏览验证与离线端到端同步推进。

出口：主动打开不足 1.2 秒仍有一条历史；刷新/旋转/五次正文更新不加次数；离开再开有新事件；重启、断网可查；X 退出不清库。真实站点不通过时不得称 Alpha，但可以继续离线开发其他模块。

### B：独立收藏、图片、资源库与系统分享

完成 XS-07/08/09/10 的图片和链接部分。原生详情工具栏先提供「收藏到 Xs」「下载」「分享」「资料库」；经验证的卡片按钮随后加入，不阻塞核心功能。

出口：收藏不向 X 发书签/点赞请求；单图/图组真实落盘；资源能预览、分类与追溯；分享后由用户在目标应用选择会话；取消、清理和权限不损坏源文件。入站“分享到 Xs”不是对外分享的替代品。

### C：转帖、视频与清爽界面

完成 XS-11/12/13。优先直达完整视频与少量稳定精简规则；不要等完整流媒体或高级知识库才提供核心精简体验。

出口：成功转帖和撤销分别有状态；视频输出完整且能在目标应用读取/播放；关闭过滤恢复页面，登录、安全提示和编辑器不受影响。

### D：可选停留与发布加固

完成 XS-14/15，以及实际需要的流媒体/批量能力。真实需求和证据决定扩展格式，不默认做通用下载引擎或四平台同步交付。

出口：长帖/遮罩/后台边界正确；容量不静默清收藏；备份恢复与升级验证；每个声称支持的接收应用都有版本化验收证据。

## 5. 数据与状态设计约束

拟引入/调整的实体：library、legacy_scope_mapping、post、post_snapshot、history_event、favorite、category/tag/note、own_action、download_task、asset、asset_post_relation、share_lease。字段和具体迁移版本在代码实施前用测试锁定；本文不声称已经有新 Schema。

- 资料所有者用 library_id；浏览器用 browser_profile_id；本人行为用 actor_hint/provenance。三者不得混为一个账号字段。
- 旧 account_id 命名空间保留来源。先做快照/备份、事务迁移与完整性校验，后续显式选择合并；失败保留原库。
- 同一 navigationId 只有一个 OPEN_POST。快照可以更新/版本化，不再盲目把“更长”当作唯一正确标准。
- LOCAL_SAVE 作为历史链接收录语义保留；新 FAVORITE 是明确本地收藏关系。迁移不能凭空增加阅读或 X 社交行为。
- 下载状态至少包括排队、解析、下载中、暂停/等待、完成、失败、取消；不支持恢复时不能显示虚假的“已暂停可续传”。
- 只有校验并完成的实际文件进入可分享集合；临时片段、签名 URL、浏览器会话、数据库不进分享目录。
- 各入口的保存/导入/收藏/下载完成/删除使用统一写入顺序；排队任务携带代次，写入前重查。清理目标库不影响其他资料或网页会话。

## 6. 默认交互与隐私

首次使用解释本地库与网页登录不同，历史需用户开启一次，之后点开自动记录；停留、过滤、媒体下载分别授权。允许暂停记录/无增强浏览，不强制新建 Xs 云账号。

收藏按钮一次完成收藏，分类面板随后选；收藏不默认下载整组视频。取消收藏、删历史、删文件、清缓存、退出 X、删整库是不同操作。

对外分享默认只包含选定内容与必要出处，不夹带私人备注、账号线索或有令牌的媒体 URL。不自动压缩/转码/加水印；目标不支持时给出原帖链接、单项或系统文件导出等明确替代。

不读取密码、验证码、Cookie/Token、私信、草稿、隐藏应用状态或任意网络响应。不为微信/QQ/飞书/Telegram 获取通讯录、聊天令牌或无障碍发送权限。

## 7. 执行纪律

从 XS-01 开始，接着并行 XS-02/03 和观察夹具，再完成 XS-04/05 的最小闭环。不要继续堆叠手动收藏入口、重复计划或 APK 白名单来替代主路径。

每个实现提交应关联 XS 编号和验收项；完成判定需真实代码、命令结果和对应环境证据。新功能先在开发构建测试，真机未验证项保持 NOT RUN。会话受限时提交可核验的阶段工作与阻塞点，不宣称后台自动继续。

运行时改动至少执行现有项目检查、Java/SQLite、Android 构建/Lint 和相关仪器测试；真实账号/接收应用检查另行记录。本文档整理不代表执行了这些运行时测试。
