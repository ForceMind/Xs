# Xs 产品要求 / Product requirements

更新：2026-11-06。状态：用户确认的产品要求，不代表功能已实现。

本次范围以 [ADR-0002](adr/0002-local-library-media.md) 和 [本机资料库、下载与分享实施规范](LOCAL_LIBRARY_MEDIA_PLAN.zh-CN.md) 为准；在资料归属、记录触发、收藏、媒体与分享方面优先于旧 Web-first 计划。Web-first 路线、安全边界和既有数据保留要求继续有效。

## 定位

在 Xs 内使用官方 X 网页浏览与社交，Xs 提供独立于 X 账号的本机历史、收藏、分类、资源下载和分享。主体验是正常刷 X 并自动找回内容，不是强迫每条内容手动分享给一个收藏工具。系统“分享到 Xs”作为补充入口保留。

不新建社交后端，不重新打包官方 APK，不复制账号凭证。系统 WebView 浏览底座可参考 ChatGPT Studio 的已评估实现；站点观察器必须为 X 单独实现。

## 1. 点开即记录，停留另记

首次由用户开启“打开历史”后，在 Xs 内主动点开帖子并进入有效详情上下文，就建立 OPEN_POST 事件；**不要求停留 1.2 秒，也不要求额外点保存**。正文尚未就绪时保存已确认的帖子 ID / 链接和打开时间，标记 LINK_ONLY，后续补正文而不增加访问次数。点击未成功进入详情不能虚构“已打开”。

同次导航的页面重绘、正文补载、刷新、旋转和状态恢复不增加次数；离开后再次主动打开可建立新访问事件。按导航身份去重，不能只靠消息序号。

“刷到／停留”是独立的 FEED_VISIBLE 事件和独立开关。基线为前台连续可见 1200ms，至少 60% 的约定可阅读区域；长帖不得因整张卡片高于屏幕而永远无法达标。背景、遮罩、登录页、私信、编辑器和预取不计。不得把停留记录称为已读证明。

## 2. 本人帖子与转帖

本人原帖、回复、引用和转帖可形成单独的行为索引。仅在动作已确认成功或从已确认归属的档案导入时记录为本人行为；打开转帖菜单、失败提交、看到别人转帖，都不是本人的转帖成功。未知转帖时间保持未知；原帖发布时间、转帖行为时间、打开时间分开。

撤销转帖保留本地行为轨迹并更新其当前状态，不默默删除已收藏内容。已发布内容的历史完整性受本地观察和导入覆盖范围限制，不承诺补回未曾取得的全部记录。

## 3. Xs 自己的收藏按钮

提供明确标为“收藏到 Xs”的按钮，与 X 的平台书签、点赞和转帖分开。详情页原生工具栏先实现；经验证的帖子卡片快捷入口后续接入，不以界面注入阻塞核心收藏。

点击后本地保存帖子链接、可见正文快照和来源，并支持分类、标签、备注与按时间管理。分类/标签是本机资料库的数据，不能调用 X 书签或替用户点赞转帖。同一帖子重复收藏保持幂等。

取消收藏不自动清空阅读历史或删除已下载文件；清空历史不自动删除收藏；删除下载文件不自动删帖。不同清理范围分别确认。

## 4. 资料属于应用，不属于 X 账号

默认一个 Xs 本机资料库。退出、登录或切换 X 账号不切换或删除收藏、下载和历史；不要求 Xs 账号或云服务。以后可提供用户主动创建的私人资料空间，但不能把网页账号切换直接等同于资料空间切换。

浏览会话的 Cookie 隔离与本机资料所有权是两层机制。实际发帖/转帖账号仅是可选的行为来源元数据，不是收藏和资源的所有者。不要为保存公开帖子而强求可信 X 账号 ID。

旧 account_id 数据不得直接改成一个全局常量或无提示合并。迁移必须保留旧空间、来源、事件、分类关系，并提供用户可理解的导入/合并选择与回滚路径。

## 5. 下载和资源库

支持用户主动下载图片、图组和视频，下载后进入本机资源库。支持缩略图/本地预览、图片/视频/下载中/失败等视图、搜索、分类、来源帖子、大小和时间、重试/取消、选择文件分享和删除。

图片和可访问的完整视频文件先实现；实际站点采用 HLS/DASH 时单独验证授权、分段、合并和可分享输出，不能把 blob URL、播放列表或片段改名当完整视频。仅访问当前用户有权访问且允许下载的资源，不绕过 DRM、付费权限或站点安全限制。

下载不等于缓存，缓存淘汰不能删掉用户主动保存的资源。默认应用私有存储；用户可主动导出到系统相册/文件。收藏默认不自动下载所有媒体，避免流量和容量失控；可提供“收藏并下载所选媒体”的明确动作。

## 6. 分享到手机上已安装的应用与会话

支持原帖链接、正文加出处、单图、多图、视频文件和用户明确选择的文件。主路径是原生系统分享菜单：选择微信、QQ、飞书、Telegram 或其他支持对应格式的已安装应用，再选择会话并确认发送。

通过 ACTION_SEND / ACTION_SEND_MULTIPLE、真实 MIME、受限 content URI 和临时只读授权分享文件，不上传 Xs 中转服务器，不读取通讯录，不索取聊天应用令牌，不用无障碍自动点击发送。系统直接联系人入口由接收应用提供，不能保证每个应用都直接显示会话，也不能声称分享菜单关闭代表发送成功。

目标应用不支持多图/视频或文件过大时，保留原文件并提供单文件、原帖链接或系统文件导出等明确降级。默认不自动压缩、改码、添加水印或附带私人备注。

## 7. 实际交付顺序

A. 浏览底座、X 特定导航/登录与自动打开历史；同时可在离线夹具验证观察器和写入。
B. Xs 独立收藏、分类、图片下载、本地资源列表、图片/链接系统分享；不以多账号或完整桥接平台阻塞首个可用版本。
C. 本人转帖记录、标准视频下载与分享、下载恢复、经验证的可撤销广告/会员提示精简。
D. 可选停留记录、图组批量操作、实际需要的 HLS/DASH、容量治理与备份恢复。

真实 X 登录、站点解析与目标应用分享能力均按具体设备和版本验收；模拟器通过不等于真机或所有社交应用已支持。

## English summary

Xs owns the local library independently of X accounts. A deliberate detail open records history without a dwell threshold; optional feed exposure is a different event. Confirmed own repost actions, app-native favorites, local image/video downloads, asset organization and Android system sharing are product requirements. X logout must not delete the local library. This update changes requirements, not runtime implementation or license grants.
